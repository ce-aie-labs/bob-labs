# Provenance and licence

## The application

`app/` is **Spring PetClinic REST**, version 2.1.5, from
<https://github.com/spring-petclinic/spring-petclinic-rest>.

It is not vendored into IBM Bob Labs.
`script/build-attachment` fetches it from upstream at the pinned tag `v2.1.5`
(commit `2cd2f9c`) and layers the files below on top of it, so this repository does
not carry a copy of someone else's application.

The project is licensed under the **Apache License 2.0**.
Upstream declares the licence but ships no licence file at this tag, so we add the full
text at [`app/LICENSE.txt`](app/LICENSE.txt).
The copyright headers in the source are the upstream project's own - none were removed.
The 25 source files without a header are in that state upstream.

### What was changed

Four files, and nothing in the application itself:

| File | Change |
|---|---|
| `app/mvnw`, `app/mvnw.cmd` | regenerated by `mvn wrapper:wrapper -Dmaven=3.9.9` |
| `app/.mvn/wrapper/maven-wrapper.properties` | Maven 3.3.3 → 3.9.9 |
| `app/.mvn/wrapper/maven-wrapper.jar` | removed - 3.9.9 uses the script-only distribution and does not need it |
| `app/LICENSE.txt` | added - the Apache 2.0 text upstream does not ship at this tag |

Maven 3.3.3 dates from 2015 and will not run on JDK 21, so without this the lab would
require a second JDK before anything could be built.
**No application source, resource, test or `pom.xml` was touched** - the labs quote numbers
taken from this exact tree (169 tests, 102 `@Test` methods, 225 assertions), so it has to
stay as it was.
The four files above live in `overlay/` in the Bob Labs repository and are the complete
difference from upstream `v2.1.5`.

## Everything else in this folder

`check.java`, `START-HERE.md` and `NOTICE.md` were written for these labs and are part of
[IBM Bob Labs](https://github.com/ce-aie-labs/bob-labs).

`petclinic-legacy.jar` is `app/` built by `script/build-attachment`, shipped so the first
thing anyone does is watch the application work rather than wait for a build.
