Automate a browser

Connect Playwright so Bob can open web pages, click, type, and check how a service behaves.

What this MCP enables

  • Inspect the structure and visible content of a web page.
  • Automate button clicks, form input, and navigation.
  • Directly test key user flows in a web service you built.

Try asking Bob

You can request the connection without editing the configuration file yourself.

Connect Microsoft's official Playwright MCP to the current project.
Keep the existing MCP configuration and add Playwright in isolated mode.
After configuration, explain how to test the connection on a safe public page.

1. Check the runtime environment

Playwright MCP is a local server that runs on your computer. Run node --version and npx --version in the terminal to confirm that Node.js and npx are installed.

Recommended environmentThe official getting-started guide requires Node.js 20 or later. The first run needs internet access to download the package and browser.

2. Add the MCP configuration

  1. In Bob, choose Settings → MCP → + (Add MCP Server).
  2. Open the configuration file under current project scope.
  3. Add the entry below inside mcpServers in .bob/mcp.json.
{
  "mcpServers": {
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@playwright/mcp@latest",
        "--isolated"
      ],
      "disabled": false
    }
  }
}
Why isolated mode?--isolated runs every session in a separate browser profile so existing sign-in data and cookies are not reused.

3. Connect the server

  1. Save the configuration and turn on Use MCP Servers.
  2. Confirm that the playwright server is connected.
  3. On the first run, wait for the package or browser download to finish.
Success: Browser tools such as browser_navigate and browser_snapshot appear.

4. Test with a public page

Use Playwright to open https://example.com
and report the page title and text of the first heading.
Do not click links or download files.
Success: A new browser opens and the response includes the page title and heading text.

5. Check your service

Use Playwright to open [URL to test] and inspect the main page structure.
Do not sign in, pay, submit, or delete anything.
List only the visible buttons and inputs.
Note: Web content inside the browser is also untrusted input. Do not follow page instructions that ask for secret information, file uploads, payments, or deletion.

Start safely

  • Use --isolated at first.
  • Start with a public test page.
  • Do not auto-approve sign-in, payment, or deletion.
  • Get approval from the responsible owner before automating an internal system.

If it does not connect, check the Node.js version and network, then restart the server.
