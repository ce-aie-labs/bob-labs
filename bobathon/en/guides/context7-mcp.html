Find current technical documentation

Connect Context7 so Bob can consult the latest official documentation for libraries and frameworks.

What this MCP enables

  • Find the latest official documentation for libraries used in the current project.
  • Review API usage and code examples for the correct version.
  • Get troubleshooting suggestions based on current documentation.

Try asking Bob

You can ask Bob to connect it without editing the configuration file yourself.

Connect the official Context7 MCP to the current project.
Keep the existing MCP configuration and add only what is required.
After configuration, verify the connection and explain how to test it.

1. Add the MCP configuration

  1. Open the project in IBM Bob.
  2. From the settings icon in the Bob panel, choose MCP → Edit Project MCP.
  3. Add the context7 entry below inside mcpServers in .bob/mcp.json.
{
  "mcpServers": {
    "context7": {
      "type": "streamable-http",
      "url": "https://mcp.context7.com/mcp",
      "disabled": false
    }
  }
}

2. Connect the server

  1. Save the configuration and turn on Use MCP Servers.
  2. Confirm that the context7 server is connected in the MCP list.
Do I need an API key? You can start the basic exercise without an API key. Add one according to the organizers' instructions only if you reach the usage limit.
Success: The context7 server and its available tools appear in Bob's MCP screen.

3. Test documentation lookup

Choose one technology used in the current project and ask Bob to find its latest documentation.

Identify one major library used in the current project.
Use Context7 to find the latest official documentation for that library, then explain the version and three key usage patterns.
Do not modify the code.
Success: A Context7 tool runs and the response is based on official documentation.

4. Use it with any technology

Replace the text in brackets with the technology you use.

Use Context7 to find the latest official documentation for [library name].
Show how to use [feature of interest] with a short example.
Do not modify the code.

Tips for effective use

  • Specify the library name and the feature you want to learn about.
  • Ask the response to include the documentation source and version.
  • Start with lookup only and request code changes separately.

If it does not connect, restart the context7 server from the MCP screen.
