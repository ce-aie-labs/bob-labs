Search current web information

Connect Exa so Bob can search the web and inspect the full text of relevant pages.

What this MCP enables

  • Find current news, market trends, and competitor information on the web.
  • Read source pages and summarize key points with links.
  • Compare multiple sources to validate ideas or produce research findings.

Try asking Bob

You can request the connection in natural language without editing the configuration file yourself.

Connect the official Exa MCP to the current project.
Keep the existing MCP configuration and add only what is required.
After configuration, verify the connection and explain how to test web search.

1. Add the MCP configuration

  1. Open the project in IBM Bob.
  2. From the settings icon in the Bob panel, choose MCP → Edit Project MCP.
  3. Add the exa entry below inside mcpServers in .bob/mcp.json.
{
  "mcpServers": {
    "exa": {
      "type": "streamable-http",
      "url": "https://mcp.exa.ai/mcp",
      "disabled": false
    }
  }
}
Already have an MCP configuration? Do not replace the entire mcpServers object. Add a comma after the existing server entry, then add only the exa entry.

For example, if Notion is already configured, keep both servers together like this.

{
  "mcpServers": {
    "notion": {
      "type": "streamable-http",
      "url": "https://mcp.notion.com/mcp",
      "disabled": false
    },
    "exa": {
      "type": "streamable-http",
      "url": "https://mcp.exa.ai/mcp",
      "disabled": false
    }
  }
}

2. Connect the server

  1. Save the configuration and turn on Use MCP Servers.
  2. Confirm that the exa server is connected in the MCP list.
Do I need an API key? You can start the basic exercise without an API key. Usage may be limited without one. If you need more capacity, obtain an Exa API key and add it according to the organizers' instructions.
Success: The exa server and tools such as web_search_exa and web_fetch_exa appear in Bob's MCP screen.

3. Test web search

Search a topic that requires current information and include the sources.

Use Exa to find three major generative AI announcements from the past week.
Put the announcement date, key point, and source link for each item in a table.
Do not modify the code.
Success: An Exa search tool runs and the result includes dates and source links.

4. Test source retrieval

Choose one search result and ask Bob to read and summarize the source page.

Choose the most important result you just found and use Exa to inspect the source page.
Summarize three key points and their relevance to our project, and include the source link.
Do not modify the code.

Tips for effective use

  • Specify the time range and number of results.
  • Ask for source links and publication dates in every response.
  • Verify search results against the source before making important decisions.

If it does not connect, restart the exa server from the MCP screen.
