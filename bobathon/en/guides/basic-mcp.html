Template 01

Connect a basic MCP to Bob

Choose either method A or B to connect an MCP in the way that works best for you.

Method A. Add it through Bob chat

With Bob's build-mcp-server skill, you can describe what you need in natural language and ask Bob to create and connect the MCP.

Create and connect an MCP for the current project.

- What I want to do: [example: search an internal announcements API and retrieve the source]
- API or data to use: [API documentation URL or data location]
- Authentication required: [none / API key / OAuth / not sure]

Use the build-mcp-server skill, add the required files and configuration,
then explain how to run it and verify the connection.
Check first: Do not paste secret keys into chat or code. Review the files Bob will change and the commands it will run.
Method A complete: If you followed Bob's instructions and verified the connection, you can skip method B below.

Method B - 1. Check the connection details

To configure it manually instead of through chat, follow steps 1 through 5 in order.

In the MCP guide, find the server name, connection type (type), and server address (url). If configuration code is provided, you can copy it as-is.

What is MCP? It is a common protocol that lets Bob connect to external tools and information such as Notion and technical documentation.

Method B - 2. Open the MCP settings

  1. Open the project where you want to use the MCP in Bob.
  2. Select the Settings icon at the lower left, then open the MCP menu.
  3. Select + (Add MCP Server) to the right of the server list.

Method B - 3. Choose the configuration scope

Under Configuration Scope, choose where the MCP configuration will apply.

  • Current project name (for example, bob_tutorial): use it only in the project you currently have open. This scope is recommended for the hackathon.
  • Global (All Workspaces): apply it to every project opened in Bob. Choose this only when you will reuse the same MCP across multiple projects.
Recommended: Choose the current project when connecting for the first time or using the MCP only for the hackathon.

Method B - 4. Edit the configuration file

Selecting Open Configuration File opens the configuration for your chosen scope. With project scope, Bob creates or opens .bob/mcp.json in the current project.

Where is .bob/mcp.json?

The project root is the project folder shown at the top of the Explorer when you open Bob.

my-project/          ← project root
├── .bob/
│   └── mcp.json      ← project MCP configuration
├── src/
└── README.md

It is fine if the .bob folder is not visible. Selecting Open Configuration File opens the file for the chosen scope directly.

Add the server configuration inside the mcpServers object and save the file. If this is your first server, you can start with the basic structure below.

{
  "mcpServers": {
    "my-tool": {
      "type": "streamable-http",
      "url": "URL provided by the MCP server",
      "disabled": false
    }
  }
}
Note: This is the basic shape for a remote HTTP connection. If the MCP provides different instructions, follow its official configuration.
Already have an MCP configuration? Do not create another mcpServers object or overwrite the existing one. Add a comma after the closing brace of the existing server entry, then place the new server entry on the next line.

For example, if Notion is already configured and you are adding Exa, keep both servers together like this.

{
  "mcpServers": {
    "notion": {
      "type": "streamable-http",
      "url": "https://mcp.notion.com/mcp",
      "disabled": false
    },
    "exa": {
      "type": "streamable-http",
      "url": "https://mcp.exa.ai/mcp",
      "disabled": false
    }
  }
}

Method B - 5. Verify the connection

  1. Save the configuration file and turn on Enable MCP tools for new tasks.
  2. Confirm that the new server appears in the MCP list.
  3. If the server requires authentication, select Authenticate and follow the authorization steps.
  4. In a new Bob task, ask Bob to use the MCP and check the result.
Success: The server appears in the MCP list and its tools can be called from a new task.

Keep in mind

  • Project scope is recommended for hackathon exercises.
  • Do not delete existing mcpServers entries.
  • Do not add passwords or tokens unless the template explicitly requires them.
