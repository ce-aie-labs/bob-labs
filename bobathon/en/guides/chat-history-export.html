Export your Bob chat history

Save your Bobathon conversation as a JSON file.

1. Choose the conversation to export

In Recent Tasks, open the ⋮ menu beside the conversation you want to export and choose Export.

2. Choose JSON format

For the export format, choose JSON · Structured data format (.json).

3. Submit your result

Open the Bobathon submission site and attach the exported JSON file.

Submit a Bobathon result Open submission site →
Check: Confirm that the JSON file is attached on the submission site, then finish your submission.

Before submitting

  • Confirm that the conversation contains no company, customer, or personal information.
  • Do not submit it if it contains passwords, API keys, or tokens.
  • Submit only conversations in which you participated.
