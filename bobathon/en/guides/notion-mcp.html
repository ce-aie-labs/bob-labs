Connect Notion MCP

Connect IBM Bob to Notion through OAuth, then verify it safely with read-only requests.

What this MCP enables

  • Find and summarize documents and meeting notes in Notion.
  • Organize ideas or work results in a new Notion page.
  • Review or update tasks and statuses in a project database.

Try asking Bob

You can ask Bob to connect it without editing the configuration file yourself.

Connect the official Notion MCP to the current project.
Keep the existing MCP configuration and add only what is required.
After configuration, explain how to authenticate and verify the connection.

1. Add the Notion configuration

Is this your first time opening MCP settings? The basic MCP connection guide shows Add MCP Server, scope selection, and the location of .bob/mcp.json with screenshots.
  1. In Bob, choose Settings → MCP → + (Add MCP Server).
  2. For Bobathon, choose current project scope, then select Open Configuration File.
  3. Add the configuration below to .bob/mcp.json. If a configuration already exists, add only the notion entry inside mcpServers.
{
  "mcpServers": {
    "notion": {
      "type": "streamable-http",
      "url": "https://mcp.notion.com/mcp",
      "disabled": false
    }
  }
}

2. Authenticate with Notion

What is OAuth? OAuth lets you approve Bob's access from a Notion sign-in page without entering your Notion password or token directly into Bob.
  1. Save the configuration and turn on Enable MCP tools for new tasks.
  2. Select Authenticate beside the notion server. If the button is disabled, sign in to Bob first.
  3. In the Notion authorization page that opens in your browser, choose the workspace to use.
  4. Confirm that you opened this page directly by selecting Authenticate in Bob and that the redirect address is http://127.0.0.1:.../callback. Then check I know and trust this URL and select Continue.
Success: The notion server appears as connected in Bob's MCP screen.

3. Start with read tools only

Notion MCP provides both read and write tools within the connected user's access. Start by enabling only read tools in Bob.

  1. Expand the notion server in Bob's MCP screen to open the tool list.
  2. Read tools: Enable only tools whose names include search, fetch, get, list, or query.
  3. Write tools: Disable tools whose names include create, update, move, or duplicate.
  4. Do not enable Always allow or automatic approval for write actions.
Important: This is a safeguard that prevents write-tool use in Bob. Notion OAuth itself does not become read-only, so use write features only on a separate test page.

4. Verify the connection

First, verify the connection with a request that does not read or modify content.

Show the currently connected Notion workspace and user information.
Do not read or modify content. Return connection information only.
Success: The connected workspace and user information are displayed.

5. Test read access

Once connected, search only for page titles you can access.

Find only five page titles I can access in my Notion.
Do not modify page content.
Success: Five accessible page titles are displayed without any changes.

6. Disconnect after Bobathon

If you used a shared computer or do not want to leave the connection active after Bobathon, disconnect it in this order.

  1. In Bob, open Settings → MCP and select Reset auth for the notion server. This clears the Notion OAuth credentials stored in Bob.
  2. Delete the notion entry from .bob/mcp.json or set "disabled": true. If you are not using other MCPs, turn off Enable MCP tools for new tasks.
  3. To review the connection in Notion, go to Settings → Connections → Notion MCP → Manage and select View all MCP clients.
  4. Find IBM Bob and the local callback address in the list. If Disconnect appears in your connection management screen, select it to remove your personal connection.
Note: Restart restarts only the server and does not clear authentication. Disconnect all users in Notion's management screen is an administrator action that disconnects the entire workspace. Participants should remove only their own personal connection.

Start safely

  • Do not put a Notion password or API token in the configuration.
  • Do not add an Authorization header.
  • Initially enable read tools only and do not auto-approve write tools.
  • A company workspace may require administrator approval.

If Authenticate is disabled, sign in to Bob first. If it still does not appear after sign-in, restart the notion server.
