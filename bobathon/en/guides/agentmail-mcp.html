Template 08

Give Bob an agent email inbox

Connect AgentMail so Bob can create a dedicated inbox, review messages, and prepare replies and outgoing email.

Important: This does not connect an existing personal or company mailbox. It creates a separate agent email address and inbox in AgentMail.

What this MCP enables

  • Create a dedicated email address and inbox for Bob to use.
  • Search incoming messages and threads, then summarize the information you need.
  • Automate email drafts, replies, forwarding, and attachment review.

Try asking Bob

Connect the official remote MCP through OAuth and begin with read tools only.

Connect the official AgentMail MCP to the current project.
Keep the existing MCP configuration and add only what is required for OAuth.
After connecting, do not create, send, or delete any email.
Explain how to check only the authenticated identity and available inboxes.

1. Understand what AgentMail connects

AgentMail does not import a personal Gmail or company mailbox. It provides a separate inbox that an AI agent can use to receive and send email.

If you need to access existing email, calendars, and contacts, the Nylas MCP guide is a better fit.

  1. Sign up or sign in to the AgentMail Console.
  2. Start with a test organization and inbox instead of company data.
  3. If you belong to multiple organizations, identify the one you will use for Bobathon.

2. Add the AgentMail configuration

Opening MCP settings for the first time? The basic MCP connection guide shows Add MCP Server, scope selection, and the location of .bob/mcp.json with screenshots.
  1. In Bob, choose Settings -> MCP -> + (Add MCP Server).
  2. For Bobathon, choose current project scope, then select Open Configuration File.
  3. Add the agentmail entry below inside mcpServers in .bob/mcp.json.
{
  "mcpServers": {
    "agentmail": {
      "type": "streamable-http",
      "url": "https://mcp.agentmail.to/mcp",
      "disabled": false
    }
  }
}
Note: If other servers already exist, keep the full mcpServers object and add only the agentmail entry. Do not put an API key in the configuration when using OAuth.

3. Authenticate with AgentMail

  1. Save the configuration, then open Settings in Bob, select the MCP tab, and turn on Use MCP Servers (Enable MCP tools for new tasks).
  2. Select Authenticate beside the agentmail server.
  3. Sign in on the AgentMail Console page that opens and review the requested access.
  4. If you belong to multiple AgentMail organizations, choose the organization to connect and approve access.
Success: The agentmail server appears as connected in Bob and its tool list is available.

4. Create a new inbox and send a test email

Use the following prompts in order to verify the AgentMail connection with Bob.

(1) Create a new inbox

Create one new AgentMail inbox for a Bobathon test.
When it is ready, show me the generated email address and display name.
Check: Bob creates a new inbox and shows its AgentMail email address.

(2) Send a test email to yourself

Replace [my email address] with an actual email address that you can check.

Send a simple test email from the AgentMail inbox we just created to my email address.

- Recipient: [my email address]
- Subject: Bobathon AgentMail connection test
- Body: The AgentMail MCP connection is working.

Show me the recipient, subject, and body before sending and wait for my confirmation.
After I confirm, send the email exactly once.
Check: Review the recipient and content before approving the email.

(3) Confirm delivery

Check your email inbox for the test message. (If it is not there, check your spam folder as well.)

You can also open the AgentMail Console, select the inbox you created, and check Sent to confirm that the message was sent.

Note: You can use various MCP tools for additional tasks, such as searching for and summarizing today's news.

5. Clean up after the exercise

  1. First confirm whether you still need the test inbox and its messages.
  2. If deletion is required, have Bob show the exact target again and approve the action once.
  3. Reset the agentmail authentication in Bob's MCP screen.
  4. Delete the agentmail entry from .bob/mcp.json or set "disabled": true.

Start safely

  • Keep personal or company mailboxes separate from an AgentMail inbox.
  • Use a test inbox and an email address that you can check yourself.
  • Review the recipient, subject, and body before sending.
  • Do not auto-approve email sending or deletion.

If authentication does not open, check your Bob sign-in and AgentMail account, then restart the agentmail server.
