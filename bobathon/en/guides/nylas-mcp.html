Connect email and calendars

Connect Nylas so Bob can use email, calendar, and contact information in your workflow.

What this MCP enables

  • Search received email and summarize the information you need.
  • Review calendar events and available times.
  • Find contacts and prepare email drafts or new calendar events.

Try asking Bob

Do not paste an API key into chat. Use the request below to have Bob show only where the key belongs.

Connect the official Nylas MCP to the current project.

After configuration, explain how to verify the connection using read tools only.

1. Prepare Nylas

To use Nylas MCP, you need a Nylas API key and a Grant connected to an email or calendar account.

  1. Create a test application in the Nylas Dashboard.
  2. Connect an email or calendar account to create a Grant.
  3. Create an API key and confirm whether your data region is the United States (US) or Europe (EU).
Important: An API key is a secret like a password. Do not include it in chat, screenshots, or Git commits, and revoke or rotate it after testing.

2. Add the MCP configuration

  1. In Bob, choose Settings → MCP → + (Add MCP Server).
  2. Under current project scope, select Open Configuration File.
  3. Add the entry below inside mcpServers in .bob/mcp.json, then replace the placeholder with the actual key.
{
  "mcpServers": {
    "nylas": {
      "type": "streamable-http",
      "url": "https://mcp.us.nylas.com",
      "headers": {
        "Authorization": "Bearer <NYLAS_API_KEY>"
      },
      "disabled": false
    }
  }
}
Using the EU region?Change the URL to https://mcp.eu.nylas.com. If servers already exist, keep the full mcpServers object and add only the nylas entry.

3. Connect and test read access

  1. Save the configuration and turn on Use MCP Servers.
  2. Confirm that the nylas server is connected and its tool list appears.
  3. At first, disable tools that send messages or create and modify events, or deny their approval requests.
Check the account connected through Nylas,
then show only the subject and sender of the five most recent emails.
Do not send, modify, or delete email.
Success: Recent email information from the connected account appears without modification.

4. Use it safely

Use Nylas to review my calendar events for this week and organize them by date.
Do not create a new event or modify an existing one.

When you need a write action, ask Bob to show the target, recipient, and time first. Review the details, then approve a single execution.

5. Clean up after the exercise

  1. Delete the nylas entry containing the API key from .bob/mcp.json.
  2. Revoke or rotate the test API key in the Nylas Dashboard.
  3. Disconnect any test Grant you no longer need.

Start safely

  • Connect a test account first.
  • Do not auto-approve email sending or calendar changes.
  • Do not commit a configuration file containing an API key.
  • Use the URL that matches your US or EU data region.

If you receive a 401 error, check the API key and Bearer format.
