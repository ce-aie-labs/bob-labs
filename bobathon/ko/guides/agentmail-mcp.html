Bob에 에이전트용 이메일 연결하기

AgentMail을 연결해 Bob이 전용 이메일함을 만들고, 메시지를 확인하고, 답장과 발송을 준비하게 합니다.

주의: 기존 개인 또는 회사 메일함을 연결하는 것이 아니라, AgentMail에서 별도의 에이전트용 이메일 주소와 받은편지함을 만드는 방식입니다.

이 MCP를 연결하면

  • Bob이 사용할 전용 이메일 주소와 받은편지함을 만들 수 있습니다.
  • 수신 메시지와 스레드를 검색하고 필요한 내용을 요약할 수 있습니다.
  • 이메일 초안, 답장, 전달, 첨부 파일 확인 같은 이메일 업무를 자동화할 수 있습니다.

Bob에게 이렇게 요청해보세요

공식 원격 MCP를 OAuth로 연결하고, 처음에는 읽기 도구로만 확인합니다.

현재 프로젝트에 공식 AgentMail MCP를 연결해줘.
기존 MCP 설정은 유지하고 OAuth 방식으로 필요한 설정만 추가해줘.
연결 후에는 메일을 만들거나 보내거나 삭제하지 말고,
인증 정보와 접근 가능한 받은편지함을 확인하는 방법만 알려줘.

1. AgentMail 용도 확인

AgentMail은 개인 Gmail이나 회사 메일함을 가져오는 서비스가 아닙니다. AI 에이전트가 직접 이메일을 받고 보낼 수 있도록 별도의 이메일함을 제공하는 서비스입니다.

기존 메일, 일정, 연락처를 조회하려는 경우에는 Nylas MCP 가이드가 더 적합합니다.

  1. AgentMail Console에 가입하거나 로그인합니다.
  2. 회사 데이터 대신 테스트용 조직과 이메일함으로 먼저 실습합니다.
  3. 여러 조직에 속해 있다면 Bobathon에 사용할 조직을 미리 확인합니다.

2. AgentMail 설정 추가

MCP 설정 화면을 처음 여나요? 기본 MCP 연결 안내에서 Add MCP Server, 범위 선택, .bob/mcp.json 위치를 이미지와 함께 먼저 확인할 수 있습니다.
  1. Bob의 설정 -> MCP -> + (Add MCP Server)를 선택합니다.
  2. Bobathon에서는 현재 프로젝트 범위를 선택하고 Open Configuration File을 누릅니다.
  3. .bob/mcp.json의 mcpServers 안에 아래 agentmail 항목을 추가합니다.
{
  "mcpServers": {
    "agentmail": {
      "type": "streamable-http",
      "url": "https://mcp.agentmail.to/mcp",
      "disabled": false
    }
  }
}
주의: 기존 서버가 있다면 mcpServers 전체를 덮어쓰지 말고 agentmail 항목만 추가합니다. OAuth 연결에서는 API 키를 설정 파일에 넣지 않습니다.

3. AgentMail 인증

  1. 설정을 저장한 뒤 Bob의 Settings에서 MCP 탭으로 이동하고 Use MCP Servers (Enable MCP tools for new tasks)를 켭니다.
  2. agentmail 서버 옆의 Authenticate를 선택합니다.
  3. 브라우저에 열린 AgentMail Console에서 로그인하고 요청된 접근 권한을 확인합니다.
  4. 여러 AgentMail 조직에 속해 있다면 사용할 조직을 선택하고 연결을 승인합니다.
성공 기준: Bob의 MCP 화면에서 agentmail 서버가 연결 상태이고 도구 목록이 표시됩니다.

4. 새 받은편지함을 만들고 테스트 메일 보내기

Bob에게 아래 프롬프트를 순서대로 요청해 AgentMail 연결을 확인합니다.

(1) 새 받은편지함 만들기

AgentMail에 Bobathon 테스트용 받은편지함을 새로 하나 만들어줘.
완료되면 생성된 이메일 주소와 표시 이름을 알려줘.
확인: Bob이 새 받은편지함을 만들고 생성된 AgentMail 이메일 주소를 알려줍니다.

(2) 내 이메일로 테스트 메일 보내기

[내 이메일 주소]를 본인이 직접 확인할 수 있는 실제 이메일 주소로 바꿔 입력합니다.

방금 만든 AgentMail 받은편지함에서 내 이메일 주소로 간단한 테스트 메일을 보내줘.

- 받는 사람: [내 이메일 주소]
- 제목: Bobathon AgentMail 연결 테스트
- 내용: AgentMail MCP 연결이 정상적으로 완료되었습니다.

보내기 전에 수신자, 제목, 본문을 먼저 보여주고 내 확인을 받아.
내가 확인하면 메일을 한 번만 보내줘.
확인: 수신자와 내용을 확인한 뒤 메일 발송을 승인합니다.

(3) 전송 결과 확인

본인의 이메일 받은편지함에서 테스트 메일이 도착했는지 확인합니다. (메일이 보이지 않으면 스팸함도 확인하세요.)

AgentMail Console에 직접 접속해 생성한 받은편지함을 열고 Sent에서 메일이 발송되었는지도 확인할 수 있습니다.

참고: 다양한 MCP 도구를 이용해 오늘 뉴스를 검색하고 요약하는 등 여러 추가 작업을 해 볼 수 있습니다.

5. 실습 후 정리

  1. 테스트 받은편지함과 메시지가 더 이상 필요 없는지 먼저 확인합니다.
  2. 삭제가 필요하면 Bob이 삭제 대상을 다시 보여주게 한 뒤 한 번만 승인합니다.
  3. Bob의 MCP 화면에서 agentmail 인증을 초기화합니다.
  4. .bob/mcp.json에서 agentmail 항목을 삭제하거나 "disabled": true로 변경합니다.

안전하게 시작하기

  • 개인 또는 회사 메일함과 AgentMail 전용 이메일함을 구분합니다.
  • 테스트용 받은편지함과 본인이 확인할 수 있는 이메일 주소를 사용합니다.
  • 발송 전 수신자, 제목, 본문을 확인합니다.
  • 메일 발송과 삭제를 자동 승인하지 않습니다.

인증 화면이 열리지 않으면 Bob 로그인 상태와 AgentMail 계정을 확인한 뒤 agentmail 서버를 Restart하세요.
