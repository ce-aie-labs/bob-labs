Bob에 기본 MCP 연결하기

방법 A, B 중 편한 방법을 선택해서 MCP를 연결할 수 있습니다.

방법 A. Bob 채팅으로 추가하기

Bob의 build-mcp-server 스킬을 활용하면 필요한 기능을 자연어로 설명해 MCP 생성과 연결을 요청할 수 있습니다.

현재 프로젝트에서 사용할 MCP를 만들어서 연결해줘.

- 하고 싶은 일: [예: 사내 공지 API를 검색하고 원문 가져오기]
- 사용할 API 또는 데이터: [API 문서 URL이나 데이터 위치]
- 필요한 인증: [없음 / API 키 / OAuth / 잘 모르겠음]

build-mcp-server 스킬을 사용하고, 필요한 파일과 설정을 추가한 뒤
실행 방법과 연결 확인 방법도 알려줘.
확인: 비밀 키는 채팅이나 코드에 그대로 입력하지 말고, Bob이 변경할 파일과 실행 명령을 먼저 확인하세요.
방법 A 완료: Bob의 안내대로 연결 확인까지 마쳤다면 아래 방법 B는 진행하지 않아도 됩니다.

방법 B — 1. 연결 정보 확인

채팅 대신 직접 설정하려면 아래 1~5단계만 순서대로 진행합니다.

사용하려는 MCP 안내에서 서버 이름, 연결 방식(type), 서버 주소(url)를 확인합니다. 템플릿에서 설정 코드가 제공된다면 그대로 복사해도 됩니다.

MCP란? Bob이 Notion이나 기술 문서 같은 외부 도구와 정보를 사용할 수 있도록 연결하는 공통 규격입니다.

방법 B — 2. MCP 설정 화면 열기

  1. Bob에서 MCP를 사용할 프로젝트를 엽니다.
  2. 왼쪽 아래의 설정 아이콘을 누른 뒤 MCP 메뉴로 이동합니다.
  3. 서버 목록 오른쪽의 + (Add MCP Server) 버튼을 누릅니다.

방법 B — 3. 적용 범위 선택

Configuration Scope에서 MCP 설정을 사용할 범위를 선택합니다.

  • 현재 프로젝트 이름 (예: bob_tutorial): 지금 연 프로젝트에서만 사용합니다. 해커톤 실습에는 이 범위를 권장합니다.
  • Global (All Workspaces): Bob에서 여는 모든 프로젝트에 적용합니다. 같은 MCP를 여러 프로젝트에서 계속 사용할 때 선택하세요.
권장: 처음 연결하거나 해커톤 프로젝트에서만 사용할 때는 현재 프로젝트 이름을 선택하세요.

방법 B — 4. 설정 파일 작성

Open Configuration File을 누르면 선택한 범위의 설정 파일이 열립니다. 프로젝트 범위를 선택했다면 현재 프로젝트의 .bob/mcp.json이 만들어지거나 열립니다.

.bob/mcp.json은 어디에 있나요?

프로젝트 루트는 Bob을 열었을 때 왼쪽 파일 탐색기(Explorer)의 맨 위에 표시되는 프로젝트 폴더입니다.

내-프로젝트/          ← 프로젝트 루트
├── .bob/
│   └── mcp.json      ← 프로젝트 MCP 설정 파일
├── src/
└── README.md

.bob 폴더가 보이지 않아도 괜찮습니다. Open Configuration File을 누르면 선택한 범위의 파일이 바로 열립니다.

열린 파일의 mcpServers 객체 안에 사용할 서버 설정을 추가하고 저장합니다. 처음 설정하는 경우에는 아래 기본형으로 시작할 수 있습니다.

{
  "mcpServers": {
    "my-tool": {
      "type": "streamable-http",
      "url": "MCP 서버에서 안내한 URL",
      "disabled": false
    }
  }
}
주의: 위 코드는 원격 HTTP 방식의 기본 형태입니다. 연결하려는 MCP가 다른 설정을 안내한다면 해당 MCP의 공식 설정을 우선 사용하세요.
기존 MCP 설정이 있나요? mcpServers 객체를 새로 만들거나 전체를 덮어쓰지 마세요. 기존 서버 항목의 닫는 중괄호 뒤에 쉼표를 추가하고, 그다음 줄에 새 서버 항목을 이어서 넣습니다.

예를 들어 Notion을 이미 사용하고 있고 Exa를 새로 연결한다면 다음과 같이 두 서버를 함께 둡니다.

{
  "mcpServers": {
    "notion": {
      "type": "streamable-http",
      "url": "https://mcp.notion.com/mcp",
      "disabled": false
    },
    "exa": {
      "type": "streamable-http",
      "url": "https://mcp.exa.ai/mcp",
      "disabled": false
    }
  }
}

방법 B — 5. 연결 확인

  1. 설정 파일을 저장하고 Enable MCP tools for new tasks를 켭니다.
  2. MCP 목록에 추가한 서버가 나타나는지 확인합니다.
  3. 인증이 필요한 서버라면 Authenticate를 눌러 안내에 따라 승인합니다.
  4. 새 Bob 작업에서 해당 MCP를 사용하도록 요청해 결과를 확인합니다.
성공 기준: MCP 목록에 서버가 표시되고, 새 작업에서 해당 도구를 호출할 수 있습니다.

기억할 점

  • 해커톤 실습은 프로젝트 범위를 권장합니다.
  • 기존 mcpServers 항목을 지우지 않습니다.
  • 비밀번호나 토큰은 템플릿이 명시적으로 요구하지 않는 한 설정에 넣지 않습니다.
