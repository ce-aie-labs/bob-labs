Notion MCP 연결하기

IBM Bob과 Notion을 OAuth로 연결한 뒤 읽기 전용 요청으로 안전하게 확인합니다.

이 MCP를 연결하면

  • Notion에서 필요한 문서와 회의록을 찾아 요약할 수 있습니다.
  • 아이디어나 작업 결과를 새 Notion 페이지로 정리할 수 있습니다.
  • 프로젝트 데이터베이스의 할 일과 상태를 확인하거나 업데이트할 수 있습니다.

Bob에게 이렇게 요청해보세요

설정 파일을 직접 편집하지 않고 연결을 요청할 수도 있습니다.

현재 프로젝트에 공식 Notion MCP를 연결해줘.
기존 MCP 설정은 유지하고, 필요한 설정만 추가해줘.
설정이 끝나면 인증 방법과 연결 확인 방법도 알려줘.

1. Notion 설정 추가

MCP 설정 화면을 처음 여나요? 기본 MCP 연결 안내에서 Add MCP Server, 범위 선택, .bob/mcp.json 위치를 이미지와 함께 먼저 확인할 수 있습니다.
  1. Bob의 설정 → MCP → + (Add MCP Server)를 선택합니다.
  2. Bobathon에서는 현재 프로젝트 범위를 선택하고 Open Configuration File을 누릅니다.
  3. 열린 .bob/mcp.json에 아래 설정을 넣습니다. 기존 설정이 있다면 mcpServers 안에 notion 항목만 추가합니다.
{
  "mcpServers": {
    "notion": {
      "type": "streamable-http",
      "url": "https://mcp.notion.com/mcp",
      "disabled": false
    }
  }
}

2. Notion 인증

OAuth란? Notion 비밀번호나 토큰을 Bob에 직접 입력하지 않고, Notion 로그인 화면에서 Bob에 허용할 접근 권한을 승인하는 방식입니다.
  1. 설정을 저장하고 Enable MCP tools for new tasks를 켭니다.
  2. notion 서버 옆의 Authenticate를 선택합니다. 버튼이 비활성화되어 있다면 먼저 Bob에 로그인하세요.
  3. 브라우저에 열린 Notion 승인 화면에서 사용할 워크스페이스를 선택합니다.
  4. Bob에서 Authenticate를 눌러 직접 열린 화면이고 이동 주소가 http://127.0.0.1:.../callback인지 확인한 뒤, 이 URL을 알고 신뢰합니다를 체크하고 계속하기를 누릅니다.
성공 기준: Bob의 MCP 화면에서 notion 서버가 연결 상태로 표시됩니다.

3. 읽기 도구만 먼저 사용

Notion MCP는 연결한 사용자가 접근할 수 있는 범위에서 읽기와 쓰기 도구를 함께 제공합니다. 처음에는 Bob에서 읽기 도구만 켜고 시작합니다.

  1. Bob의 MCP 화면에서 notion 서버를 펼쳐 도구 목록을 엽니다.
  2. 읽기 도구: 이름에 search, fetch, get, list, query가 포함된 도구만 켭니다.
  3. 쓰기 도구: create, update, move, duplicate가 포함된 도구는 끕니다.
  4. Always allow 또는 쓰기 자동 승인은 켜지 않습니다.
중요: 이것은 Bob에서 쓰기 도구 사용을 막는 안전장치입니다. Notion OAuth 자체는 별도의 읽기 전용 권한으로 바뀌지 않으므로, 쓰기 기능은 반드시 별도의 테스트용 페이지에서만 사용하세요.

4. 연결 확인

먼저 콘텐츠를 읽거나 수정하지 않는 요청으로 연결 정보를 확인합니다.

현재 연결된 Notion 워크스페이스와 사용자 정보를 확인해줘.
읽거나 수정하지 말고 연결 정보만 알려줘.
성공 기준: 연결된 워크스페이스와 사용자 정보가 표시됩니다.

5. 읽기 테스트

연결이 확인되면 접근 가능한 페이지 제목만 검색합니다.

내 Notion에서 접근 가능한 페이지 제목 5개만 찾아줘.
페이지 내용은 수정하지 마.
성공 기준: 수정 없이 접근 가능한 페이지 제목 5개가 표시됩니다.

6. Bobathon 종료 후 연결 해제

공용 PC를 사용했거나 Bobathon 종료 후 연결을 남기고 싶지 않다면 아래 순서로 해제합니다.

  1. Bob의 설정 → MCP에서 notion 서버의 Reset auth를 선택합니다. Bob에 저장된 Notion OAuth 인증 정보가 지워집니다.
  2. .bob/mcp.json에서 notion 항목을 삭제하거나 "disabled": true로 변경합니다. 다른 MCP도 사용하지 않는다면 Enable MCP tools for new tasks를 끕니다.
  3. Notion에서도 연결 상태를 확인하려면 설정 → 연결 → Notion MCP → 관리에서 모든 MCP 클라이언트 보기를 선택합니다.
  4. 목록에서 IBM Bob과 로컬 callback 주소를 확인합니다. 본인의 연결 관리 화면에 Disconnect가 표시되면 이를 선택해 개인 연결을 해제합니다.
주의: Restart는 서버만 다시 시작하며 인증 정보를 지우지 않습니다. Notion 관리 화면의 모든 사용자 연결 해제하기는 워크스페이스 전체 사용자의 연결을 끊는 관리자 기능입니다. 참가자는 누르지 말고 본인의 개인 연결만 해제하세요.

안전하게 시작하기

  • Notion 비밀번호나 API 토큰을 설정에 넣지 않습니다.
  • Authorization 헤더를 추가하지 않습니다.
  • 처음에는 읽기 도구만 켜고 쓰기 도구를 자동 승인하지 않습니다.
  • 회사 워크스페이스는 관리자 승인이 필요할 수 있습니다.

Authenticate가 비활성화되어 있다면 먼저 Bob에 로그인합니다. 로그인 후에도 보이지 않으면 notion 서버를 Restart하세요.
