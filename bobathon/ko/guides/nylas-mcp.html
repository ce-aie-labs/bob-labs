이메일과 일정 연결하기

Nylas를 연결해 Bob이 이메일, 캘린더, 연락처 정보를 업무에 활용하게 합니다.

이 MCP를 연결하면

  • 받은 이메일을 검색하고 필요한 내용을 요약할 수 있습니다.
  • 캘린더 일정과 가능한 시간을 확인할 수 있습니다.
  • 연락처를 찾고 이메일 초안이나 새 일정을 준비할 수 있습니다.

Bob에게 이렇게 요청해보세요

API 키를 채팅에 붙여 넣지 말고, 아래 요청으로 필요한 설정 위치만 안내받으세요.

현재 프로젝트에 공식 Nylas MCP를 연결해줘.
기존 MCP 설정은 유지하고, API 키는 내가 직접 입력할 수 있도록 자리만 표시해줘.
설정이 끝나면 읽기 도구만 사용해 연결을 확인하는 방법도 알려줘.

1. Nylas 사전 준비

Nylas MCP를 사용하려면 Nylas API 키와 이메일 또는 캘린더가 연결된 Grant가 필요합니다.

  1. Nylas Dashboard에서 테스트용 애플리케이션을 준비합니다.
  2. 이메일 또는 캘린더 계정을 연결해 Grant를 만듭니다.
  3. API 키를 발급하고 데이터 리전이 미국(US)인지 유럽(EU)인지 확인합니다.
중요: API 키는 비밀번호와 같은 비밀 정보입니다. 채팅, 화면 캡처, Git 커밋에 포함하지 말고 테스트가 끝나면 폐기하거나 교체하세요.

2. MCP 설정 추가

  1. Bob의 설정 → MCP → + (Add MCP Server)를 선택합니다.
  2. 현재 프로젝트 범위에서 Open Configuration File을 누릅니다.
  3. .bob/mcp.json의 mcpServers 안에 아래 항목을 추가하고 자리 표시자를 실제 키로 바꿉니다.
{
  "mcpServers": {
    "nylas": {
      "type": "streamable-http",
      "url": "https://mcp.us.nylas.com",
      "headers": {
        "Authorization": "Bearer <NYLAS_API_KEY>"
      },
      "disabled": false
    }
  }
}
EU 리전을 사용하나요?URL을 https://mcp.eu.nylas.com으로 바꾸세요. 기존 서버가 있다면 mcpServers 전체를 덮어쓰지 말고 nylas 항목만 추가합니다.

3. 연결 및 읽기 테스트

  1. 설정을 저장하고 Use MCP Servers를 켭니다.
  2. nylas 서버가 연결 상태이고 도구 목록이 표시되는지 확인합니다.
  3. 처음에는 메시지 전송, 일정 생성·수정 도구를 끄거나 승인 요청이 나타날 때 거부합니다.
Nylas에서 연결된 계정을 확인한 뒤,
최근 받은 이메일의 제목과 보낸 사람 5개만 보여줘.
메일을 보내거나 수정하거나 삭제하지 마.
성공 기준: 연결된 계정의 최근 이메일 정보가 수정 없이 표시됩니다.

4. 안전하게 활용하기

Nylas로 이번 주 내 캘린더 일정을 조회해 날짜별로 정리해줘.
새 일정을 만들거나 기존 일정을 수정하지 마.

쓰기 기능이 필요하면 대상·수신자·시간을 먼저 보여 달라고 요청하고, 내용을 확인한 뒤 한 번만 실행하도록 승인합니다.

5. 실습 후 정리

  1. .bob/mcp.json에서 API 키가 포함된 nylas 항목을 삭제합니다.
  2. Nylas Dashboard에서 테스트용 API 키를 폐기하거나 교체합니다.
  3. 더 이상 필요하지 않은 테스트 Grant를 연결 해제합니다.

안전하게 시작하기

  • 처음에는 테스트 계정을 연결합니다.
  • 이메일 전송과 일정 변경은 자동 승인하지 않습니다.
  • API 키가 포함된 설정 파일은 커밋하지 않습니다.
  • US/EU 데이터 리전에 맞는 URL을 사용합니다.

401 오류가 나오면 API 키와 Bearer 형식을 확인하세요.
