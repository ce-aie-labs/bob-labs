최신 기술 문서 찾기

Context7를 연결해 Bob이 라이브러리와 프레임워크의 최신 공식 문서를 참고하게 합니다.

이 MCP를 연결하면

  • 현재 프로젝트에서 사용하는 라이브러리의 최신 공식 문서를 찾을 수 있습니다.
  • 정확한 버전에 맞는 API 사용법과 코드 예제를 확인할 수 있습니다.
  • 최신 문서를 바탕으로 오류 해결 방법을 제안받을 수 있습니다.

Bob에게 이렇게 요청해보세요

설정 파일을 직접 편집하지 않고 연결을 요청할 수도 있습니다.

현재 프로젝트에 공식 Context7 MCP를 연결해줘.
기존 MCP 설정은 유지하고, 필요한 설정만 추가해줘.
설정이 끝나면 연결 상태를 확인하고 테스트 방법도 알려줘.

1. MCP 설정 추가

  1. IBM Bob에서 프로젝트를 엽니다.
  2. Bob 패널의 설정 아이콘에서 MCP → Edit Project MCP를 선택합니다.
  3. .bob/mcp.json의 mcpServers 안에 아래 context7 항목을 추가합니다.
{
  "mcpServers": {
    "context7": {
      "type": "streamable-http",
      "url": "https://mcp.context7.com/mcp",
      "disabled": false
    }
  }
}

2. 서버 연결

  1. 설정을 저장하고 Use MCP Servers를 켭니다.
  2. MCP 목록에서 context7 서버가 연결 상태인지 확인합니다.
API 키가 필요한가요? 기본 실습은 API 키 없이 시작할 수 있습니다. 사용량 제한에 걸린 경우에만 운영진 안내에 따라 키를 추가하세요.
성공 기준: Bob의 MCP 화면에서 context7 서버와 사용 가능한 도구가 표시됩니다.

3. 문서 조회 테스트

현재 프로젝트에 사용된 기술 하나를 골라 최신 문서를 찾아보게 합니다.

현재 프로젝트에서 사용하는 주요 라이브러리 하나를 확인해줘.
Context7에서 해당 라이브러리의 최신 공식 문서를 찾아 버전과 핵심 사용법 3가지를 설명해줘.
코드는 수정하지 마.
성공 기준: Context7 도구가 실행되고 공식 문서를 바탕으로 한 설명이 표시됩니다.

4. 원하는 기술로 활용

대괄호 안을 참가자가 사용하는 기술로 바꿉니다.

Context7에서 [라이브러리 이름]의 최신 공식 문서를 찾아
[알고 싶은 기능]의 사용법과 짧은 예제를 보여줘.
코드는 수정하지 마.

잘 활용하는 방법

  • 라이브러리 이름과 알고 싶은 기능을 구체적으로 적습니다.
  • 답변에 참고한 문서와 버전을 함께 표시해 달라고 요청합니다.
  • 처음에는 조회만 하고 코드 수정은 별도로 요청합니다.

연결되지 않으면 MCP 화면에서 context7 서버를 Restart하세요.
