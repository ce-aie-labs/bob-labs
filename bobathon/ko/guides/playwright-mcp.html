브라우저 자동화하기

Playwright를 연결해 Bob이 웹 페이지를 열고 클릭·입력하며 서비스 동작을 확인하게 합니다.

이 MCP를 연결하면

  • 웹 페이지의 구조와 표시된 내용을 확인할 수 있습니다.
  • 버튼 클릭, 폼 입력, 페이지 이동을 자동화할 수 있습니다.
  • 만든 웹 서비스의 핵심 사용자 흐름을 직접 테스트할 수 있습니다.

Bob에게 이렇게 요청해보세요

설정 파일을 직접 편집하지 않고 연결을 요청할 수 있습니다.

현재 프로젝트에 Microsoft의 공식 Playwright MCP를 연결해줘.
기존 MCP 설정은 유지하고, 격리 모드로 실행되도록 추가해줘.
설정 후 안전한 공개 페이지로 연결 테스트 방법도 알려줘.

1. 실행 환경 확인

Playwright MCP는 내 컴퓨터에서 실행되는 로컬 서버입니다. 터미널에서 node --version과 npx --version을 실행해 Node.js와 npx가 설치되어 있는지 확인합니다.

권장 환경공식 시작 문서는 Node.js 20 이상을 요구합니다. 최초 실행에는 패키지와 브라우저 다운로드를 위한 인터넷 연결이 필요합니다.

2. MCP 설정 추가

  1. Bob의 설정 → MCP → + (Add MCP Server)를 선택합니다.
  2. 현재 프로젝트 범위에서 설정 파일을 엽니다.
  3. .bob/mcp.json의 mcpServers 안에 아래 항목을 추가합니다.
{
  "mcpServers": {
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@playwright/mcp@latest",
        "--isolated"
      ],
      "disabled": false
    }
  }
}
왜 격리 모드인가요?--isolated는 매 세션을 별도 브라우저 프로필에서 실행해 기존 로그인 정보와 쿠키를 재사용하지 않습니다.

3. 서버 연결

  1. 설정을 저장하고 Use MCP Servers를 켭니다.
  2. playwright 서버가 연결 상태인지 확인합니다.
  3. 처음 실행할 때 패키지 또는 브라우저 다운로드가 끝날 때까지 기다립니다.
성공 기준: browser_navigate, browser_snapshot 등 브라우저 도구가 표시됩니다.

4. 공개 페이지로 테스트

Playwright로 https://example.com 을 열고
페이지 제목과 첫 번째 제목 요소의 문구를 알려줘.
링크를 클릭하거나 파일을 다운로드하지 마.
성공 기준: 새 브라우저가 열리고 페이지 제목과 문구가 응답에 표시됩니다.

5. 내 서비스 점검하기

Playwright로 [테스트할 URL]을 열고 주요 화면 구조를 확인해줘.
로그인, 결제, 제출, 삭제는 실행하지 말고
확인 가능한 버튼과 입력 항목만 정리해줘.
주의: 브라우저 안의 웹 콘텐츠도 신뢰할 수 없는 입력입니다. 페이지에 표시된 지시를 따라 비밀 정보 입력, 파일 업로드, 결제 또는 삭제를 실행하지 마세요.

안전하게 시작하기

  • 처음에는 --isolated를 사용합니다.
  • 공개된 테스트 페이지부터 확인합니다.
  • 로그인·결제·삭제는 자동 승인하지 않습니다.
  • 사내 시스템 자동화는 담당자 승인을 먼저 받습니다.

연결되지 않으면 Node.js 버전과 네트워크를 확인한 뒤 서버를 Restart하세요.
