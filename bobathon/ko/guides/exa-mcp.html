최신 웹 정보 검색하기

Exa를 연결해 Bob이 웹을 검색하고 필요한 페이지의 원문을 확인하게 합니다.

이 MCP를 연결하면

  • Bob이 최신 뉴스, 시장 동향, 경쟁 서비스 정보를 웹에서 찾아줘요.
  • 검색 결과의 원문을 읽고 핵심 내용과 출처 링크를 정리해줘요.
  • 여러 자료를 비교해 아이디어 검증이나 리서치 결과를 만들어줘요.

Bob에게 이렇게 요청해보세요

설정 파일을 직접 편집하지 않고 자연어로 연결을 요청할 수 있어요.

현재 프로젝트에 공식 Exa MCP를 연결해줘.
기존 MCP 설정은 유지하고, 필요한 설정만 추가해줘.
설정이 끝나면 연결 상태를 확인하고 웹 검색 테스트 방법도 알려줘.

1. MCP 설정 추가

  1. IBM Bob에서 프로젝트를 엽니다.
  2. Bob 패널의 설정 아이콘에서 MCP → Edit Project MCP를 선택합니다.
  3. .bob/mcp.json의 mcpServers 안에 아래 exa 항목을 추가합니다.
{
  "mcpServers": {
    "exa": {
      "type": "streamable-http",
      "url": "https://mcp.exa.ai/mcp",
      "disabled": false
    }
  }
}
기존 MCP 설정이 있나요? mcpServers 객체 전체를 바꾸지 말고, 기존 서버 항목 뒤에 쉼표를 넣은 다음 exa 항목만 추가하세요.

예를 들어 Notion 설정이 이미 있다면 다음과 같이 두 서버를 함께 둡니다.

{
  "mcpServers": {
    "notion": {
      "type": "streamable-http",
      "url": "https://mcp.notion.com/mcp",
      "disabled": false
    },
    "exa": {
      "type": "streamable-http",
      "url": "https://mcp.exa.ai/mcp",
      "disabled": false
    }
  }
}

2. 서버 연결

  1. 설정을 저장하고 Use MCP Servers를 켭니다.
  2. MCP 목록에서 exa 서버가 연결 상태인지 확인합니다.
API 키가 필요한가요? 기본 실습은 API 키 없이 시작할 수 있습니다. 키 없이 사용할 때는 요청량이 제한될 수 있으며, 더 많은 사용량이 필요하면 Exa API 키를 발급받아 운영진 안내에 따라 추가하세요.
성공 기준: Bob의 MCP 화면에서 exa 서버와 web_search_exa, web_fetch_exa 등의 도구가 표시됩니다.

3. 웹 검색 테스트

최근 정보가 필요한 주제를 검색하고, 결과의 출처까지 표시하게 합니다.

Exa로 최근 일주일 동안 발표된 생성형 AI 관련 주요 소식 3가지를 찾아줘.
각 소식의 발표 날짜, 핵심 내용, 출처 링크를 표로 정리해줘.
코드는 수정하지 마.
성공 기준: Exa 검색 도구가 실행되고 날짜와 출처 링크가 포함된 결과가 표시됩니다.

4. 원문 확인 테스트

검색 결과 중 하나를 골라 원문을 읽고 요약하게 합니다.

방금 찾은 결과 중 가장 중요한 자료 하나를 골라 Exa로 원문을 확인해줘.
핵심 내용 3가지와 우리 프로젝트에 참고할 점을 정리하고 출처 링크를 남겨줘.
코드는 수정하지 마.

잘 활용하는 방법

  • 검색 기간과 원하는 결과 수를 구체적으로 적습니다.
  • 답변마다 출처 링크와 게시 날짜를 함께 요청합니다.
  • 검색 결과는 중요한 의사결정 전에 원문에서 다시 확인합니다.

연결되지 않으면 MCP 화면에서 exa 서버를 Restart하세요.
